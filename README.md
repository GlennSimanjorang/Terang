# Terang

Starter project Next.js dengan App Router dan TypeScript.

## Menjalankan proyek

```bash
npm install
npm run dev
```

Buka http://localhost:3000. Edit `app/page.tsx` untuk mulai membangun halaman.

## Docker

Jalankan versi production dengan Docker Compose:

```bash
docker compose up --build
```

Buka http://localhost:3000. Untuk menghentikan container, jalankan `docker compose down`.
